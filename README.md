# HTML5 视频播放器增强脚本

## 功能

| 按键 | 功能 |
|---|---|
| **X** | 减速 0.1x |
| **C** | 加速 0.1x |
| **Z** | 在 1x 原速与当前倍速间切换 |
| **Ctrl+←** | 快退 30 秒 |
| **Ctrl+→** | 快进 30 秒 |

## 安装

1. 安装 [Violentmonkey](https://violentmonkey.github.io/) 或 [Tampermonkey](https://www.tampermonkey.net/)
2. 点击下方链接自动安装：
   
   [点此安装](https://raw.githubusercontent.com/Failuredoll/h5player-userscript/main/HTML5.user.js)

> 也可直接点击本仓库中 `HTML5.user.js` → Raw 按钮安装

## 支持的网站

所有使用 HTML5 `<video>` 标签的视频网站，包括 B站、YouTube、抖音、腾讯视频、优酷、爱奇艺等。
